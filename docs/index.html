SyncSet

Seamlessly replicate databases across instances with high-performance batching and smart conflict resolution.

Quick Start

Install SyncSet directly from PyPI:

pip install syncset-db

Usage

Configure your replication settings in a YAML file and run the syncer using the --file flag:

# Test your configuration
syncset --file=sync.yaml --dry-run

# Run the replication
syncset --file=sync.yaml

Example Configuration

primary_db:
  url: "postgresql://user:pass@localhost:5432/primary"

replica_dbs:
  - name: replica_1
    url: "postgresql://user:pass@localhost:5433/replica"

tables:
  users:
    primary_key: id
    mode: upsert
    batch_size: 5000

Key Features

Multi-Table Sync

Replicate multiple tables simultaneously from a single primary to multiple replicas.

Smart Upsert

High-performance conflict resolution using Postgres native ON CONFLICT logic.

Batch Processing

Memory-efficient streaming and batching for handling millions of rows effortlessly.
